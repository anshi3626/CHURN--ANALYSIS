# Customer Churn Data Analytics

## Project Overview
This project analyzes customer churn data using Python, Pandas, SQLite, Matplotlib, and Seaborn. It combines customer, subscription, and customer-support information to explore churn behavior, calculate business KPIs, and visualize patterns that may help understand customer retention.

## Objectives
- Clean and prepare customer, subscription, and support data.
- Combine the datasets using `customerid`.
- Create a churn indicator and other analytical features.
- Calculate key churn and customer metrics.
- Explore relationships between escalations and churn.
- Visualize churn trends and compare churn across plans and states.
- Practice SQL operations with SQLite through Python.

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite (`sqlite3`, included with Python)

## Analysis Workflow
1. Connect to the SQLite database and inspect available tables.
2. Load the tables into Pandas DataFrames.
3. Clean customer, subscription, and support data:
   - Rename and remove selected columns.
   - Convert date columns to datetime.
   - Standardize gender values.
   - Fill missing country values using state-country mapping.
   - Remove duplicate support records after calculating complaint counts.
4. Merge the datasets using `customerid`.
5. Create analytical features such as `churn_flag`, `tenure_days`, and `churn_risk`.
6. Calculate metrics including:
   - Churn rate and retention rate
   - Churn by plan type
   - Average revenue per user (ARPU)
   - Average customer tenure
   - Revenue at risk
   - Escalation rate
   - Average complaints per user
   - Correlation between escalation and churn
7. Create visualizations using Matplotlib and Seaborn.
8. Perform SQL table creation, insertion, selection, and aggregation using SQLite.

## How to Run
1. Clone or download this repository.
2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Make sure `customer_churn.db` is in the same directory as the notebook.
4. Open Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
5. Open `DATA ANALYTICS.ipynb` and run the cells in order.

## Notes
- The notebook uses the relative database path `customer_churn.db`.
- `exported_churn_data.csv` is generated by the notebook; it can be regenerated by running the relevant export cell.
- The tenure calculation uses the date on which the notebook is executed for customers without a cancellation date. Therefore, the average tenure can change on a later run.
- Results depend on the contents of the database and the execution date.
